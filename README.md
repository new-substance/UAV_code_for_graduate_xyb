## 只读状态与组件检查

在仓库根目录的MATLAB R2023a会话中执行：

```matlab
addpath('matlab_mvp');
setup_project;
status = project('status'); % 新设计、迁移状态与未放行原因
cfg = project('config');   % 带project_context的旧数值输入
```

`project('check')`仍可核对保留组件的固定输入代数、写入限额及旧4＋1等接口，不启动任务；它尚未包含新已知节点导航和新通感协议的验收。无需为场景文字更新运行整套旧测试。

可选Python/NumPy固定输入原理核对，不启动任务、不写结果文件，输入数值仅是代数算例：

```powershell
python -X utf8 research_checks/check_forest_strategy_algebra.py
```

`project('run', options)`在模型审查完成前拒绝运行。下一步先固定林区地形/节点安装高度、参考布局/误差、测距硬件及监听/载荷接口，再推导辅助惯导、逐包费用和联合定位误差，在本工程迁移并重新审查配置、代码、种子及指标。不得绕过project调用旧全轨迹执行器。
